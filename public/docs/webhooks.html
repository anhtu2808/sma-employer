Webhook Documentation

Integrate real-time recruiting events into your application using SmartRecruit webhooks.

01 Overview

Webhooks allow you to build or set up integrations which subscribe to certain events on SmartRecruit. When one of those events is triggered, we'll send a POST HTTP request to the URL you configured.

Target URL

Note: Your endpoint must be publicly accessible and support HTTPS.

02 Security & Authentication

For security purposes, SmartRecruit includes a digital signature in every webhook request header.

Header: X-SmartRecruit-Signature

How to verify:

  • Retrieve the Secret Key from your SmartRecruit Dashboard.
  • Verify that the signature in the header matches your secret key.
  • Ignore any requests that fail this verification to prevent Replay Attacks.

03 Event: application.approved

This event is triggered when a recruiter approves a candidate's application. Use the resumeUrl to access the candidate's CV directly.

04 Best Practices

Respond with 2xx

Your server must return a 200 OK within 5 seconds. Otherwise, we will mark the delivery as failed.

Idempotency

Event delivery may happen more than once. We recommend making your event handling logic idempotent.
